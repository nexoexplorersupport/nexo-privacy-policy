Nexo Explorer

Privacy Policy

Last updated: November 16, 2026

1. Introduction

Nexo Explorer is an Android file management application designed to help users organize, access, manage, and transfer files on their devices. We respect user privacy and aim to keep file management operations local to the user's device.

2. Data Collection

Nexo Explorer does not intentionally collect or transmit personal information, usage analytics, or tracking data to the developer. The application does not currently integrate advertising, analytics, or crash-reporting SDKs.

3. File Access and Processing

Nexo Explorer accesses files and folders on the user's device to provide its file management features. This may include processing file names, paths, file types, sizes, and modification dates. File information is processed locally and is not uploaded to servers operated by the developer.

4. Thumbnails and Local Storage

Nexo Explorer may generate and store thumbnails and related temporary data on the user's device to improve browsing performance. These files remain stored locally and are used for the application's functionality.

5. Wireless FTP Transfers

Nexo Explorer provides optional FTP functionality for wireless file transfers between connected devices. When the user enables FTP functionality, connected devices may access permitted folders and transfer files. These transfers occur directly between the participating devices and do not pass through servers operated by the developer.

Users should only enable FTP connections on networks and with devices they trust.

6. Third-Party Services

The current version of Nexo Explorer does not integrate third-party advertising, analytics, or user-tracking services. If future versions introduce services that process personal information, this Privacy Policy will be updated accordingly.

7. Data Security

Nexo Explorer processes file management operations locally. Users remain responsible for protecting their devices and controlling access to wireless file-sharing functionality.

8. Children's Privacy

Nexo Explorer is a general-purpose file management application and is not specifically designed for children. The developer does not knowingly collect personal information from children.

9. Changes to This Privacy Policy

This Privacy Policy may be updated to reflect changes in application functionality, data practices, or applicable requirements. The latest version will be made available at the published Privacy Policy URL.
